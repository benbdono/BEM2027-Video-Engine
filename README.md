# BEM2027 Video Engine

استوديو عربي لإعداد وإنتاج فيديوهات المراجعة التعليمية الخاصة بمنصة ملخصات BEM2027.

## تشغيل المشروع
1. افتح رابط GitHub Pages أو افتح `index.html` في متصفح حديث.
2. جهّز اسم المشروع والمادة وعنوان الفيديو.
3. من «إدارة المشاهد» أضف المشاهد وعدّل العناوين والنصوص والمدد والانتقالات.
4. يمكن إرفاق صورة خلفية مستقلة بكل مشهد. تُضغط الصورة إلى JPEG قبل حفظها في بيانات المشروع.
5. من «إنتاج الفيديو» أرفق ملفاً صوتياً اختيارياً، ثم اختر «إنشاء الفيديو الآن».
6. بعد انتهاء المعالجة نزّل ملف WebM الناتج.

## ميزات الإصدار 0.2.0
- واجهة عربية RTL متجاوبة وهوية BEM2027 الداكنة بالبنفسجي والفيروزي.
- نسب إخراج 16:9 و9:16 و1:1، مع أبعاد Canvas فعلية مناسبة لكل نسبة.
- إضافة المشاهد وحذفها ونسخها وتحرير النصوص والمدد والانتقالات وظهور الروبوت.
- إرفاق صورة خلفية لكل مشهد.
- حفظ محلي للمشروع واستيراد/تصدير JSON.
- محرّك تصدير محلي داخل المتصفح باستخدام Canvas وMediaRecorder.
- دمج مسار صوتي واحد اختياري مع الفيديو.
- تصدير WebM مع شريط تقدم ووصلة تنزيل.

## حدود معروفة وخطة التطوير
- صيغة الإخراج الحالية WebM وليست MP4. إضافة MP4 تتطلب ترميزاً إضافياً مثل FFmpeg/WebAssembly أو خدمة معالجة، وسيتم اختيار حل مجاني مناسب بعد اختبار الأداء وحجم الملفات.
- الصوت الحالي ملف واحد للمشروع كله؛ لا يوجد بعد توليد صوت آلي أو مزامنة تعليق مستقل لكل مشهد.
- الرسوم الحالية تُرسم داخل Canvas، ويمكن استخدام صورة خلفية لكل مشهد؛ لا يوجد بعد توليد صور بالذكاء الاصطناعي أو تحريك فيديو واقعي.
- خيارات الانتقال المحفوظة في المحرر ستحتاج ربطاً حركياً أكثر تفصيلاً في محرك التصدير.
- التصدير يتم على جهاز المستخدم؛ قد يتطلب الفيديو الطويل ذاكرة ووقتاً كبيرين. استخدم Chrome أو Edge حديثاً، ولا تغلق الصفحة أثناء التصدير.
- لا توجد حالياً خدمة خلفية أو مفاتيح API أو حسابات خارجية مطلوبة.

## الخصوصية
المشروع يعمل من جهة المتصفح. تُحفظ إعدادات المشروع والمشاهد محلياً في LocalStorage، ولا تُرسل إلى خادم BEM2027. ملفات الصوت المختارة لا تُرفع إلى خادم؛ تُستخدم محلياً أثناء التصدير.

## GitHub Pages
من إعدادات المستودع اختر Pages ثم Deploy from a branch، والفرع `main` والمجلد `/(root)`.

# BEM2027 Video Engine

استوديو عربي لإعداد وإنتاج فيديوهات المراجعة التعليمية الخاصة بمنصة ملخصات BEM2027.

## تشغيل الاستوديو
1. افتح [نسخة GitHub Pages](https://benbdono.github.io/BEM2027-Video-Engine/) في متصفح حديث مثل Chrome أو Edge.
2. أدخل اسم المشروع والمادة وعنوان الفيديو.
3. من «إدارة المشاهد» أضف المشاهد وعدّل النصوص والمدد والانتقالات وظهور الروبوت.
4. يمكن إضافة صورة خلفية لكل مشهد. تُحوّل الصورة إلى JPEG بحجم مناسب قبل حفظها محلياً.
5. من «إنتاج الفيديو» أرفق مساراً صوتياً اختيارياً، ثم أنشئ فيديو WebM.
6. بعد نجاح WebM، يمكن طلب تحويله إلى MP4. يُحمّل محرك FFmpeg عند أول تحويل فقط.

## الميزات الحالية\n- استيراد PDF: عرض كل صفحة كصورة مشهد مع استخراج النص القابل للتحديد إن توفر. يدعم حتى 20 صفحة في الدفعة الواحدة مع ضغط الصور لحماية مساحة تخزين المتصفح.\n- استيراد عروض PowerPoint بصيغة PPTX: استخراج نصوص الشرائح وتحويلها إلى مشاهد قابلة للتحرير، مع محاولة استخراج أول صورة مرتبطة بكل شريحة. يدعم حتى 100 شريحة وحجم ملف حتى 150 MB. تُحمّل مكتبة JSZip عند طلب الاستيراد فقط.
- واجهة عربية RTL متجاوبة وهوية BEM2027 الداكنة بالبنفسجي والفيروزي.
- نسب إخراج 16:9 و9:16 و1:1، بأبعاد 1920×1080 و1080×1920 و1080×1080.
- إضافة المشاهد وحذفها ونسخها وتحرير النصوص والمدد والانتقالات وظهور الروبوت.
- صور خلفية مستقلة للمشاهد.
- حفظ محلي للمشروع والمشاهد واستيراد/تصدير بيانات المشروع بصيغة JSON.
- معاينة المشاهد وتصدير WebM باستخدام Canvas وMediaRecorder.
- مسار صوتي واحد اختياري يُدمج مع الفيديو.
- تحويل اختياري من WebM إلى MP4 عبر FFmpeg WebAssembly أحادي الخيط، بترميز H.264 وAAC.
- التحقق من رمز خروج FFmpeg ومن ترويسة MP4 قبل إظهار رابط التحميل.
- تنظيف مسارات الصوت والموارد المؤقتة بعد التصدير أو عند حدوث خطأ.

## تفاصيل MP4 والتوافق
- مكتبة الواجهة مثبتة على `@ffmpeg/ffmpeg@0.12.15` وتُحمّل من مدخل ESM الرسمي باستخدام مستورد المتصفح الأصلي، وليس UMD/webpack.
- محرك الترميز مثبت على `@ffmpeg/core@0.12.10` ويُحمّل من مجلد ESM.
- ملف عامل FFmpeg موجود داخل المستودع في `vendor/ffmpeg/worker.js` ويُشغّل كـ module worker من نفس النطاق.
- ملفات JavaScript وWASM للمحرك تُحمّل عند طلب MP4 فقط. حجم WASM يقارب 31 MB، إضافة إلى ملفات JavaScript؛ لذلك يحتاج أول تحويل إلى اتصال إنترنت وذاكرة كافية.
- المحرك أحادي الخيط لتجنب الاعتماد على SharedArrayBuffer وترويسات COOP/COEP.
- WebM يبقى متاحاً إذا فشل تحميل المحرك أو التحويل.
- نجاح فحص CI يؤكد صحة الملفات والربط البرمجي فقط. لا يُعد بديلاً عن اختبار التحويل الحقيقي في متصفح المستخدم وعلى جهازه.
- التصدير محلي داخل المتصفح. قد تستغرق الفيديوهات الطويلة وقتاً وذاكرة كبيرين؛ لا تغلق الصفحة أثناء التصدير أو التحويل.

## حدود الإصدار\n- استيراد PDF يحافظ على مظهر الصفحة كصورة ولا يحوّل عناصرها إلى طبقات تحرير منفصلة. استخراج النص يعتمد على وجود نص حقيقي داخل PDF؛ الصفحات المصورة قد لا تنتج نصاً. الحد الحالي 20 صفحة و40 MB للملف.\n- استيراد PPTX يستورد حتى 20 شريحة في الدفعة الواحدة، ويستخرج النص وأول صورة مرتبطة بالشريحة عند توفرها؛ لا يعيد بناء الحركات أو التخطيط الكامل.\n- استيراد PPTX الحالي يحوّل النصوص وأول صورة مرتبطة بكل شريحة، ولا يعيد إنتاج تخطيط PowerPoint الأصلي أو الرسوم المتجهة أو الحركات أو المخططات أو كل الصور. راجع المشاهد بعد الاستيراد. دعم PDF والتحويل المطابق بصرياً للشرائح يحتاج مرحلة منفصلة.
- لا يوجد حالياً توليد تلقائي للتعليق الصوتي أو مزامنة صوت منفصل لكل مشهد.
- وصف المشهد البصري حقل إرشادي؛ الرسومات المولدة حالياً هي عناصر Canvas والروبوت والخلفية المضافة، وليست مولداً للصور أو الفيديو بالذكاء الاصطناعي.
- الصوت ملف واحد للمشروع كله.
- لا توجد خدمة خلفية أو حسابات مستخدمين أو مفاتيح API مطلوبة.

## الخصوصية والتخزين
تُحفظ بيانات المشروع والمشاهد في LocalStorage على جهاز المستخدم. لا تُرفع ملفات المشروع أو الصوت أو الفيديو إلى خادم BEM2027. تُحمّل مكتبات FFmpeg وملفات WASM من jsDelivr عند طلب التحويل.

## الفحص الآلي
يشغّل GitHub Actions:
- `node --check app.js`
- `node --check renderer.js`
- `node scripts/validate.mjs`

تتحقق هذه الفحوص من وجود الملفات، ومراجع HTML، وانتقالات المشاهد، وأبعاد الإخراج، واستخدام FFmpeg ESM المثبت، ووجود العامل المحلي، والتحقق من رمز خروج الترميز وترويسة MP4. لا تنفذ هذه الفحوص ترميزاً فعلياً داخل متصفح.

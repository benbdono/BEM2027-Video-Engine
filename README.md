# BEM2027 Video Engine

استوديو أولي باللغة العربية لإعداد مشاريع الفيديوهات التعليمية الخاصة بمنصة ملخصات BEM2027.

## التشغيل
1. حمّل ملفات المشروع أو فك ضغط الحزمة.
2. افتح `index.html` في متصفح حديث.
3. أنشئ المشاهد وعدّل النصوص والمدد والانتقالات والوصف البصري.
4. استخدم «تصدير المشروع» لحفظ بيانات المشروع بصيغة JSON.

## النشر على GitHub Pages
1. ارفع جميع الملفات إلى جذر المستودع `BEM2027-Video-Engine` على الفرع `main`.
2. افتح Settings ثم Pages.
3. اختر Deploy from a branch، ثم `main` والمجلد `/ (root)`.
4. احفظ وانتظر اكتمال النشر. رابط الموقع سيكون عادة:
   `https://benbdono.github.io/BEM2027-Video-Engine/`

## ما يتضمنه الإصدار 0.1.0
- واجهة عربية RTL متجاوبة.
- معاينة تصميمية للمشاهد بنسبة 16:9 مع خيارات 9:16 و1:1.
- شخصية روبوت تعليمية ضمن الهوية البصرية.
- إضافة المشاهد وحذفها ونسخها وتحريرها.
- تحديد المدة والانتقال والنص والتعليق الصوتي والوصف البصري لكل مشهد.
- حفظ تلقائي محلي في المتصفح.
- استيراد وتصدير ملفات JSON.

## حدود الإصدار
هذه النسخة محرر إعداد وتجهيز للمشاهد وليست مولّداً فعلياً للفيديو. لا تنتج MP4 ولا تولّد صوراً أو تعليقاً صوتياً أو موسيقى بالذكاء الاصطناعي. هذه الوظائف تحتاج ربطاً بمحركات إنتاج مناسبة في مرحلة لاحقة.

## الخصوصية
بيانات المشروع تحفظ محلياً في المتصفح، ولا تُرسل إلى خادم خارجي. خط Alexandria اختياري ويتطلب اتصالاً بالإنترنت؛ توجد خطوط بديلة في حال عدم توفره.
